# ATProto Development Environment

An isolated local environment for developing and observing AT Protocol clients against a PDS and PLC directory, including a Go tutorial bot built with Bluesky's Indigo library.

Main components and capabilities:

- Local PDS, PLC directory, and repository browser
- PostgreSQL administration with pgAdmin
- Logs, traces, metrics, and dashboards with Grafana LGTM
- Go bot and local account-creation tooling

> **Warning:** This stack is for isolated development only. Do not expose it to untrusted networks or use it for production data or accounts.

See [DEVELOPER.md](DEVELOPER.md) for setup, operation, and testing instructions.
